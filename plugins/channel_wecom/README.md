# 企业微信远程通道插件使用说明
## 功能介绍
本插件基于企业微信自建应用实现远程双向消息桥接，无需公网IP、无需域名备案，个人用户免费即可使用，让您可以通过手机企业微信随时随地远程操作本地AI助手，复用所有本地插件能力。
## 核心特性
✅ **零门槛使用**:默认轮询模式，无需公网IP，个人企业微信即可配置
✅ **体验完全对齐**:远程对话上下文与本地工作台完全互通，支持所有插件调用
✅ **多重安全防护**:白名单鉴权、权限分级、路径校验、全量审计、速率限制
✅ **文件双向传输**:支持远程发送文本/Markdown/图片/文件，AI生成的内容自动推送到手机
✅ **稳定可靠**:消息游标、幂等校验、自动重连、异常保活，不丢消息不重复执行
## 配置步骤
### 1. 注册个人企业微信
1. 打开[企业微信官网](https://work.weixin.qq.com/)，使用个人手机号注册即可，无需企业认证
2. 登录企业微信管理后台
### 2. 创建自建应用
1. 进入「应用管理」→「自建」→「创建应用」
2. 填写应用名称（如「AI助手远程控制」），选择可见范围（添加自己的账号）
3. 创建完成后，记录下页面中的`AgentId`
4. 进入「我的企业」→「企业信息」，记录下`CorpID`
5. 点击应用详情页的`Secret`查看按钮，记录下应用密钥（**仅显示一次，请妥善保存**）
### 3. 配置可信IP
1. 在应用详情页「安全设置」→「企业可信IP」中，添加您的网络出口公网IP
2. 可访问[ip.sb](https://ip.sb/)查看您当前的公网IP
### 4. 插件配置
1. 打开AI智能助手插件市场，找到「企业微信远程通道」插件，点击配置
2. 依次填入刚才记录的`CorpID`、`AgentID`、`Secret`
3. 在「允许使用的用户ID列表」中添加您的企业微信用户ID（可在企业微信后台通讯录中查看）
4. 点击「测试连接」，收到测试消息即表示配置成功
5. 开启插件，即可在企业微信中给应用发消息使用
## 安全说明
### 默认安全策略
1. **白名单机制**:仅配置的用户ID可以发送指令，陌生人消息直接丢弃
2. **高危操作拦截**:默认禁止远程执行文件删除、系统关机、修改系统配置等操作，如需开启需本地手动确认
3. **敏感文件拦截**:禁止远程读取密码、密钥、浏览器Cookie等敏感数据
4. **全量审计**:所有远程操作、消息、文件传输都记录日志，可在插件配置页查看
5. **频率限制**:默认单用户每分钟最多20次请求，避免账号被限流
### 安全建议
1. 请勿将Secret泄露给他人，配置页面默认以密码框形式隐藏
2. 如怀疑Secret泄露，可在企业微信后台重置Secret并更新插件配置
3. 不使用时可随时在插件管理页关闭远程通道
## 常见问题
### Q: 消息收不到怎么办？
A: 请检查:1. 插件是否已启动；2. 网络是否能正常访问企业微信API；3. 应用可见范围是否包含您的账号；4. 可信IP是否配置正确。
### Q: 支持发送图片和文件吗？
A: 支持，AI生成的图片、文档会自动上传并发送到您的企业微信，单张图片自动压缩到300KB以内，大于20MB的文件会提示本地路径。
### Q: 远程对话和本地上下文互通吗？
A: 是的，插件使用相同的会话ID绑定，本地聊到一半出门可以直接用手机续接，对话历史和记忆完全同步。
### Q: 需要公网IP吗？
A: 不需要，默认采用轮询模式主动拉取消息，只要本地电脑能上网即可使用，无需端口映射、域名备案。
