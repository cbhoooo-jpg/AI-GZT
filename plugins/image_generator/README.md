# AI图片生成插件 (Image Generator)

## 📌 插件概述

**插件名称**：AI图片生成插件  
**版本**：1.1.0  
**作者**：官方插件生成  
**适用平台**：AI智能助手  
**核心模型**：火山方舟豆包 Seedream 5.0 高清生图模型  

### ✨ 核心特性
- 🎨 **高清生图**：支持 3K/4K 分辨率，无需手动填写像素值，自动适配模型最低像素要求
- 🖼️ **多模式支持**：文生图、图生图、多图融合、多角度专业卡片生成
- 📷 **本地图片转Base64**：自动将本地参考图转换为Base64格式上传，无需手动转换
- 🃏 **合一卡片模式**：自动将4张多角度图片合成为1920x2600竖版卡片，带简介和生成时间
- 🚀 **自动保存与上传**：生成图片自动保存到本地，合一卡片自动上传获取公网URL

## 📦 安装说明

### 1. 环境要求
- Python 3.8+
- 依赖库：`requests>=2.31.0`、`Pillow>=10.0.0`

### 2. 安装依赖
在项目根目录下执行以下命令安装依赖：
```bash
pip install -r plugins/image_generator/requirements.txt
```

### 3. 获取API密钥
1. 访问 [火山方舟控制台](https://console.volcengine.com/ark/region:ark+cn-beijing/openManagement)
2. 开通 Seedream 生图模型
3. 在「密钥管理」处获取 API 密钥
4. 复制模型 ID（带 `ep-` 前缀的完整值）

### 4. 插件配置
在插件配置页面填写以下信息：
| 配置项 | 说明 | 默认值 |
|--------|------|--------|
| `ark_api_key` | 火山方舟API密钥（必填） | 无 |
| `ark_api_url` | API接口地址 | `https://ark.cn-beijing.volces.com/api/v3/images/generations` |
| `ark_model_id` | 模型ID | `doubao-seedream-5-0-260128` |
| `save_path` | 图片保存路径 | `D:/AI仓库文件夹/文件生成/图片生成/` |

## 🚀 使用方法

### 核心参数说明

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| `prompt` | string | 是 | 图片生成的提示词，越详细生成效果越好 |
| `size_level` | string | 否 | 分辨率档位，可选值: `3k`/`4k`，默认 `3k` |
| `size_ratio` | string | 否 | 图片比例，可选值: `1:1`/`16:9`/`9:16`/`4:3`/`3:4`/`2:3`/`21:9`，默认 `16:9` |
| `style` | string | 否 | 图片风格，如写实、卡通、科幻、水墨画等 |
| `count` | int | 否 | 生成图片数量，默认1，最多支持4张 |
| `images` | list | 否 | 参考图列表，支持本地文件路径/URL/Base64，最多14张 |
| `card_type` | string | 否 | 卡片类型，可选值: `人物`/`场景`/`动物`/`物体` |
| `card_mode` | string | 否 | 卡片模式，可选值: `normal`/`unified`，默认 `normal` |
| `introduction` | string | 否 | 合一卡片自定义简介内容，未传值时自动生成 |

### 2. 图生图模式
基于参考图生成新图片的模式，支持本地图片自动转Base64上传。

**使用场景**:风格迁移、图片改编、二次创作、相似图扩展

**参数说明**:
| 参数 | 必填 | 说明 |
|------|------|------|
| `prompt` | 是 | 图片描述提示词，描述期望的生成效果 |
| `images` | 是 | 参考图列表，支持本地路径/URL/Base64，最多14张 |
| `size_level` | 否 | 分辨率档位，默认 `3k` |
| `size_ratio` | 否 | 图片比例，默认 `16:9` |
| `style` | 否 | 图片风格 |
| `count` | 否 | 生成数量，1-4张 |

**本地图片支持**:
- 自动检测本地文件路径，读取后转Base64上传
- 支持格式:JPG、PNG、WEBP、BMP
- 无需手动转换，直接传路径即可

**示例**:
🔹 非执行示例，仅作参考

size_level: 3k
size_ratio: 1:1
style: 科幻
count: 1
```

### 3. 多图融合模式
将多张参考图融合生成新图片，提取各图特征进行创意合成。

**使用场景**:多元素合成、风格混合、创意拼贴、概念融合

**参数说明**:
| 参数 | 必填 | 说明 |
|------|------|------|
| `prompt` | 是 | 融合描述提示词，说明如何融合各图元素 |
| `images` | 是 | 参考图列表，2-14张，支持本地路径/URL/Base64 |
| `size_level` | 否 | 分辨率档位，默认 `3k` |
| `size_ratio` | 否 | 图片比例，默认 `16:9` |
| `style` | 否 | 图片风格 |
| `count` | 否 | 生成数量，1-4张 |

**融合策略建议**:
- 2-3张图:适合风格+内容融合，如"A图的构图+B图的色彩风格"
- 4-7张图:适合多元素合成，如"提取各图中的主体元素组合到同一场景"
- 8-14张图:适合批量风格统一，如"参考所有图片的共同风格生成新图"

**示例**:
🔹 非执行示例，仅作参考
```
prompt: 融合三张参考图的风格特征，生成一张融合了日式浮世绘、赛博朋克和水墨画风格的未来城市景观
images: ["D:/图片素材/浮世绘.jpg", "D:/图片素材/赛博朋克.jpg", "D:/图片素材/水墨画.jpg"]
size_level: 4k
size_ratio: 21:9
style: 科幻
count: 1
```

### 4. 多角度卡片模式（normal）
自动生成指定类型的多角度标准化卡片，包含4个不同角度的素材图。

**使用场景**:影视素材、游戏资产、商用卡片、产品展示

**参数说明**:
| 参数 | 必填 | 说明 |
|------|------|------|
| `prompt` | 是 | 卡片主体描述提示词 |
| `card_type` | 是 | 卡片类型，可选值:`人物`/`场景`/`动物`/`物体` |
| `card_mode` | 否 | 卡片模式，设为 `normal` 或不传，默认 `normal` |
| `size_level` | 否 | 分辨率档位，默认 `3k` |
| `size_ratio` | 否 | 图片比例，默认 `16:9` |
| `style` | 否 | 图片风格 |
| `images` | 否 | 参考图，传入后会基于参考图生成卡片 |

**卡片类型说明**:
| 类型 | 生成角度 | 适用场景 |
|------|----------|----------|
| `人物` | 正面、侧面、背面、全身 | 角色设计、人物设定、演员素材 |
| `场景` | 广角、中景、近景、俯瞰 | 场景设计、环境概念图、背景素材 |
| `动物` | 正面、侧面、背面、动态 | 动物素材、宠物设计、生物设定 |
| `物体` | 正面、侧面、俯视、细节 | 产品展示、道具设计、物品素材 |

**示例**:

style: 写实
```

### 5. 合一卡片模式（unified）
将4张多角度素材图合成为一张1920×2160竖版卡片，包含素材展示区和简介区。

**使用场景**:素材展示、作品集、商业推广、社交媒体分享

**参数说明**:
| 参数 | 必填 | 说明 |
|------|------|------|
| `prompt` | 是 | 卡片主体描述提示词 |
| `card_type` | 是 | 卡片类型，可选值:`人物`/`场景`/`动物`/`物体` |
| `card_mode` | 是 | 设为 `unified`，启用合一卡片模式 |
| `introduction` | 否 | 自定义简介内容，不传则自动生成 |
| `size_level` | 否 | 分辨率档位，默认 `3k` |
| `style` | 否 | 图片风格 |
| `images` | 否 | 参考图，传入后会基于参考图生成卡片 |

**合一卡片结构**:
- **尺寸**:1920×2160 竖版
- **上半部分**:4张多角度素材图（2×2网格排列）
- **下半部分**:简介区域，包含标题、描述、生成时间
- **自动上传**:合一卡片生成后自动上传获取公网URL

**示例**:
🔹 非执行示例，仅作参考
```
prompt: 一只威武的东北虎在雪地中巡视领地
card_type: 动物
card_mode: unified
introduction: 东北虎，又称西伯利亚虎，是现存体型最大的猫科动物，主要分布于俄罗斯远东地区和中国东北部。体长可达3米，体重超过250公斤，是国家一级保护动物。
size_level: 4k
style: 写实
```

## ❓ 常见问题

### Q1:生成图片失败，提示API密钥错误？
**A**:请检查插件配置中的 `ark_api_key` 是否正确，确保复制时没有多余空格。同时确认模型ID `ark_model_id` 是否带有 `ep-` 前缀。

### Q2:本地图片无法上传？
**A**:请检查:
1. 文件路径是否正确，建议使用完整绝对路径（如 `D:/图片素材/xxx.jpg`）
2. 图片格式是否为支持的格式（JPG、PNG、WEBP、BMP）
3. 图片大小是否过大，建议单张不超过10MB

### Q3:生成图片模糊或分辨率不够？
**A**:尝试将 `size_level` 参数设为 `4k`，同时确保提示词描述足够详细，越详细的描述生成的图片细节越丰富。

### Q4:合一卡片模式生成失败？
**A**:合一卡片模式需要先成功生成4张多角度素材图，如果其中任何一张生成失败，合一卡片也会失败。建议:
1. 检查网络连接是否稳定
2. 确认API调用额度是否充足
3. 尝试降低 `size_level` 为 `3k` 后重试

### Q5:多图融合时效果不理想？
**A**:多图融合的效果很大程度上取决于提示词的描述。建议:
1. 明确说明要融合的元素和风格
2. 说明融合方式（如"提取A图的色彩+B图的构图"）
3. 适当增加风格描述，帮助模型理解期望效果

### Q6:生成速度较慢？
**A**:生成速度受以下因素影响:
1. `size_level` 设置越高，生成时间越长（4K比3K慢约30%-50%）
2. `count` 数量越多，总耗时越长
3. 合一卡片模式需要先生成4张素材图再合成，耗时约为普通模式的5倍
4. 网络状况和API服务负载也会影响速度

### Q7:如何获取最佳的图生图效果？
**A**:建议:
1. 参考图清晰度高、主体明确
2. 提示词详细描述期望的修改效果，而非简单描述原图内容
3. 适当指定 `style` 参数，帮助模型理解目标风格
