# 本地进程监控插件 (Process Monitor)

## 📌 插件说明
本地进程监控插件是一个智能化的系统安全辅助工具。它通过定时轮询系统进程列表，发现新增进程后，结合白名单机制和系统保护名单进行初步过滤，将可疑进程信息发送给AI助手进行风险判断，并根据AI返回的风险等级执行分级处置策略（自动关闭、仅通知、放行）。

## ✨ 核心功能
1. **单次扫描**:支持AI助手直接调用执行一次进程扫描，返回格式化报告，快速排查当前系统状态。
2. **持续监控**:定时扫描系统进程列表，发现新增进程并触发告警。
3. **白名单机制**:用户可配置白名单，白名单内的进程直接放行，不通知AI。
4. **系统保护名单**:硬编码的系统关键进程名单（如 `svchost.exe`、`explorer.exe` 等），防止误杀导致系统崩溃。
5. **AI风险判断**:采集进程详细信息（路径、父进程、CPU/内存占用等），发送给AI助手判断是否为恶意程序。
6. **分级处置策略**:
   - **高危**:自动终止进程 + 通知用户
   - **中危**:仅通知用户，等待确认
   - **低危**:放行，记录日志
7. **告警冷却**:同一进程在冷却时间内（默认300秒）不重复通知，避免告警刷屏。

## ⚙️ 配置说明
| 配置项 | 说明 | 类型 | 默认值 | 必填 |
| --- | --- | --- | --- | --- |
| scan_interval | 扫描间隔(秒) | number | 5 | 是 |
| enabled | 是否启用监控 | boolean | false | 是 |
| auto_start | 自动启动 | boolean | false | 否 |
| whitelist | 白名单进程列表 | array | ["chrome.exe", "code.exe", "python.exe", "pycharm64.exe", "wechat.exe"] | 否 |
| high_risk_action | 高风险处置策略 | select | auto_terminate | 是 |
| medium_risk_action | 中风险处置策略 | select | notify_only | 是 |
| low_risk_action | 低风险处置策略 | select | allow | 是 |
| session_id | AI会话ID | string | process_monitor | 是 |
| system_prompt | AI系统提示词 | text | 你收到了一条进程监控告警... | 是 |
| cooldown_seconds | 告警冷却时间(秒) | number | 300 | 是 |

## ❓ 常见问题

### Q1:监控启动失败，提示"监控未启用"？
**A**:请检查插件配置中的 `enabled` 是否设置为 `true`。该配置项控制监控功能的总开关。

### Q2:进程被误杀怎么办？
**A**:请将该进程添加到 `whitelist`（白名单进程列表）中，白名单内的进程将直接放行，不通知AI进行风险判断。

### Q3:AI助手无法判断进程风险？
**A**:请检查 `session_id` 配置项是否正确，确保AI助手服务正常运行。同时可以检查 `system_prompt` 是否被误修改，导致AI无法返回预期的JSON格式结果。

### Q4:同一进程频繁告警？
**A**:适当增大 `cooldown_seconds`（告警冷却时间）的值，默认为300秒，同一进程在冷却时间内不会重复告警。
