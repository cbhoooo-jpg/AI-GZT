# 屏幕录制插件（V1.1）

本地屏幕录制插件，为参赛演示视频等场景提供零配置录屏能力，数据 100% 本地处理。

## 功能
- 三种录制范围:主屏全屏（默认）/ 鼠标拖拽框选区域 / 指定显示器；
- 对话控制:「开始录屏」「框选区域录屏」「录第2个显示器」「暂停录屏」「继续录屏」「停止录屏」「录屏状态」；
- **暂停/继续**:录制中可随时暂停再继续，暂停片段不写入成片、不留空白段，恢复后续录同一文件；自动停止按“成片内容时长”计时，暂停时间不计入；
- **成片变速压缩**:录完可说「把刚才的录屏压缩到40秒」，如实际 60 秒自动按 1.5 倍速重编码，setpts 重排帧序、内容完整不裁剪（安全区间 0.25–4 倍），原片保留、加速版另存为 `xxx_加速_40s.mp4`；
- **独立小控制台**:双击 `启动录屏控制台.bat` 即可脱离工作台使用，纯文字按钮:开始（全屏/框选）、暂停、继续、结束并保存、关闭，结束后填“目标秒数”一键生成加速版；录制进程独立于控制台和工作台，关闭控制台不影响录制；
- mss 抓屏（多屏/高DPI坐标准确）+ ffmpeg 管道直出 H.264/yuv420p/faststart 标准 MP4，B站、腾讯视频可直接上传；
- 帧率、CRF 画质、编码预设、输出目录、防遗忘自动停止时长均可在插件配置页修改；
- 偶数像素自动对齐、帧节奏防堆积、COM 初始化、ffmpeg 异常强杀、同名文件不覆盖。

## V1.1 边界
只录画面、不录声音（演示视频后期用 edge-tts 配音对齐）；变速仅处理画面（无音轨）；麦克风/系统声音混入列入 V2。

## 架构
主程序每次调用插件均重新导入模块并同步执行 run()，录制状态无法驻留内存，故真正的录制运行在独立子进程（`python main.py --record 参数.json`），通过 runtime 目录下的文件通信:
- `status.json`:录制状态（state=starting/recording/paused/finished/error/canceled、成片内容时长、帧数、pid、输出路径等），原子写入；
- `stop.flag`:存在即通知录制进程结束并封装；
- `pause.flag`:存在即暂停抓帧（录制进程不退出、不喂帧给 ffmpeg，成片无空白段），删除即继续。

因此录制进程独立于工作台与小控制台:关掉工作台、关掉控制台都不影响正在进行的录制，可用任意新进程执行停止/继续。runtime 目录为运行时产物，不入库。

## 使用方式

### 方式一:小控制台（推荐，无需工作台）
双击插件目录下的 `启动录屏控制台.bat`:选择全屏/框选 → 开始录制 → 可随时暂停/继续 → 结束并保存；结束后在「成片变速」区填目标秒数（如实际 60 秒填 40）点「生成加速版」。

### 方式二:对话控制（工作台内）
「开始录屏」「暂停录屏」「继续录屏」「停止录屏」「录屏状态」「把刚才的录屏压缩到40秒」。

### 方式三:命令行（脱离工作台）
在插件目录执行:
- 开始:`python -c "import main; print(main.run({'action':'start','mode':'full','fps':30}))"`
- 暂停:`python -c "import main; print(main.run({'action':'pause'}))"`
- 继续:`python -c "import main; print(main.run({'action':'resume'}))"`
- 停止:`python -c "import main; print(main.run({'action':'stop'}))"`
- 变速:`python -c "import main; print(main.run({'action':'speed','target_seconds':40}))"`

## 真机自测
在插件目录执行:`python main.py selftest`，录主屏 3 秒，产物为 `runtime/selftest.mp4`。

## 配置项
| 配置项 | 说明 | 默认 |
| --- | --- | --- |
| fps | 默认帧率（5-60，参赛演示建议30） | 20 |
| crf | x264 画质，0-40，越小越清晰 | 23 |
| preset | 编码预设（ultrafast~medium） | veryfast |
| output_dir | 视频输出目录，留空为 系统视频目录/AI智能助手录屏 | 空 |
| max_seconds | 防遗忘自动停止秒数 | 1800 |
