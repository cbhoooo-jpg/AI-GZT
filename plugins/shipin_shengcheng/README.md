# 视频生成插件

## 📌 插件说明
调用AI模型生成视频，支持传入本地图片/卡片路径自动转换为公网URL，无需手动上传。支持文生视频、图生视频、视频生视频、音频替换等多种生成模式，内置专业导演视角的提示词增强引擎，自动优化镜头语言、节奏设计、画质呈现等效果。

## 📋 版本信息
- 版本:1.0.0
- 作者:官方插件生成
- 触发关键词:视频生成

## ⚙️ 配置说明
| 配置项 | 说明 | 类型 | 默认值 | 必填 |
| --- | --- | --- | --- | --- |
| api_key | 火山方舟API密钥 | password | 无 | 是 |
| api_url | API接口地址 | input | https://ark.cn-beijing.volces.com/api/v3/contents/generations/tasks | 是 |
| model_id | 模型ID | input | doubao-seedance-2-0-260128 | 是 |
| save_path | 文件保存路径 | input | D:/AI仓库文件夹/文件生成/视频生成/ | 否 |
| open_volc_ark | 前往开通模型 | button | 无 | 否 |

### 配置项详细说明

#### model_id（模型ID）
火山方舟视频生成模型ID，默认使用 Seedance 2.0 Pro 版（`doubao-seedance-2-0-260128`）。
> ⚠️ 请勿使用 fast 版本，当前账号未开通 fast 权限。

#### save_path（文件保存路径）
生成的视频文件保存的本地目录，默认为 `D:/AI仓库文件夹/文件生成/视频生成/`。

#### open_volc_ark（前往开通模型）
点击直达火山方舟控制台，可开通视频生成模型、获取API密钥、复制模型ID。

## 📝 参数说明
| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| prompt | string | 是 | 视频生成描述提示词，越详细生成效果越好 |
| size | string | 是 | 视频尺寸，支持1024x1024/1280x720/720x1280 |
| duration | string | 否 | 视频时长，单位秒，支持5/10/15/30，默认5 |
| images | list/string | 否 | 参考图片，支持本地文件路径/公网URL/列表/单字符串，图生视频时传入 |
| reference_video | string | 否 | 参考视频URL，视频生视频时传入 |
| reference_audio | string | 否 | 参考音频URL，自定义背景音乐/配音时传入 |
| generate_audio | string/boolean | 否 | 是否自动生成音频，默认true |

## ✨ 功能特性
| 功能 | 说明 | 适用场景 |
|------|------|----------|
| 文生视频 | 根据提示词生成视频，内置导演视角提示词增强 | 创意视频、广告宣传、剧情短片 |
| 图生视频 | 支持本地图片自动转Base64传入，参考图生成视频 | 图片动效、静态素材视频化、二次创作 |
| 视频生视频 | 基于参考视频URL生成新视频 | 视频改编、风格迁移、特效增强 |
| 音频替换 | 传入参考音频URL，自定义背景音乐/配音 | 视频配音、多语言适配、音乐替换 |
| 多模态融合 | 支持同时传入图片、视频、音频多模态参考素材 | 复杂场景生成、专业视频制作 |
| 导演视角增强 | 自动优化镜头语言、节奏设计、人物/产品刻画 | 提升视频专业度和观赏性 |

## ❓ 常见问题

### Q1:视频生成失败，提示API密钥错误？
**A**:请检查插件配置中的 `api_key` 是否正确，确保复制时没有多余空格。同时确认模型ID `model_id` 是否为 `doubao-seedance-2-0-260128`，请勿使用 fast 版本。

### Q2:本地图片无法上传？
**A**:插件会自动将本地图片路径转换为Base64格式直接传入模型，完全本地处理无需云端存储。请检查:
1. 文件路径是否正确，建议使用完整绝对路径（如 `D:/图片素材/xxx.jpg`）
2. 图片格式是否为支持的格式（JPG、PNG、WEBP、BMP）
3. 图片大小是否过大，建议单张不超过10MB

### Q3:参考视频/参考音频无法使用？
**A**:由于模型不支持Base64格式的视频和音频，参考视频和参考音频必须为公网URL。插件会尝试通过TOS对象存储自动上传本地文件获取公网URL，如未配置TOS或上传失败，将跳过该参考素材。请配置TOS对象存储或直接传入公网URL。

### Q4:视频生成超时？
**A**:视频生成通常需要1-5分钟，插件默认轮询超时时间为10分钟。如遇高峰期可能等待时间较长，请稍后重试。如持续超时，请检查网络连接和API服务状态。

### Q5:生成视频效果不理想？
**A**:插件内置了导演视角的提示词增强引擎，会自动优化镜头语言、节奏设计等。如效果仍不理想，建议:
1. 提示词尽量详细描述场景、人物、动作、氛围
2. 明确指定视频风格（如写实、卡通、科幻等）
3. 提供参考图/参考视频辅助模型理解期望效果

### Q6:如何获取最佳的视频生成效果？
**A**:建议:
1. 提示词结构化:先描述主体，再描述动作，最后描述环境和氛围
2. 合理设置时长:5秒适合短镜头，10-15秒适合完整情节，30秒适合复杂场景
3. 善用多模态:图生视频效果通常优于纯文生视频，有条件时尽量提供参考图
