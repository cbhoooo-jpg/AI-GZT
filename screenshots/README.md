## 如何触发 SmartScreen 蓝窗（本地方案，无需上传网盘）

在安装包所在目录打开 cmd，执行（把文件名换成实际安装包名）:

🔹 非执行示例，仅作参考

    echo [ZoneTransfer] > "AI_GZT_Setup_v1.0.exe:Zone.Identifier"
    echo ZoneId=3 >> "AI_GZT_Setup_v1.0.exe:Zone.Identifier"

打完标记后双击安装包即会出现蓝色 SmartScreen 窗口；截图完成后删除该备用流或对文件执行「属性 → 解除锁定」即可还原。
