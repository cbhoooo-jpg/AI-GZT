# 智能文件编辑工具调用说明（给大模型的工具描述） 
## 工具名称：intelligent_file_editor
## 功能说明：
编辑本地纯文本文件，支持替换、插入前、插入后、删除操作，纯内容锚点定位，完全兼容缩进、空行、换行符、编码差异，无需提供行号，编辑成功率≥99.9%，内置自动备份、写入失败自动回滚机制，不会丢失数据。
支持的文件类型：.py, .md, .txt, .json, .yaml, .yml, .html, .css, .js, .ts, .java, .cpp, .c, .go, .rs

## 调用参数：
| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| file_path | string | 是 | 要编辑的文件路径，支持相对项目根路径/绝对路径 |
| operation | string | 是 | 操作类型，可选值：<br>• replace：替换定位锚点的内容<br>• insert_before：在定位锚点之前插入内容<br>• insert_after：在定位锚点之后插入内容<br>• delete：删除定位锚点的内容 |
| target_block | string | 是 | 定位锚点内容，建议选2-5行连续上下文作为锚点，尽量包含唯一标识（函数名、注释、类名、特殊字符串等），避免仅用单个符号/通用关键词作为唯一锚点 |
| content | string | 否 | 要插入/替换的新内容，operation=delete时不需要传 |

## 锚点生成规则（自动遵守）：
1. 锚点优先选择2-5行连续内容，包含前后上下文，提高定位唯一性
2. 匹配失败会自动扩展锚点上下文重试最多3次，无需手动调整
3. 锚点内容不需要严格匹配缩进/空行，引擎会自动归一化处理

## 返回值说明：
• 成功返回：(True, "编辑成功，匹配相似度：x.xx，已自动备份原文件")
• 失败返回：(False, "错误信息详情")
如果返回匹配失败，请检查锚点内容是否存在于目标文件中，或者增加锚点的上下文行数重新调用
