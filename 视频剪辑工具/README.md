# 独立视频剪辑工具

双击即用的本地视频小工具，与 AI 智能助手主程序、插件体系完全独立，零侵入。

## 功能

- **视频裁剪**:导入视频后按时间裁剪片段。快速模式流拷贝秒出（切点对齐关键帧）；精确模式重编码，帧级精确。
- **视频拼接**:多个视频按顺序合并。快速模式流拷贝；兼容模式自动统一分辨率/帧率（缩放补黑边、缺音轨补静音），分辨率不同也能拼。
- **字幕配音**:
  - 导入标准 SRT，或在程序内逐条新增/编辑/删除字幕，可导出 SRT 备份；
  - 字幕烧录进画面，字号/顶底位置/底边距可调；
  - 勾选「同时生成字幕配音」后，用 edge-tts 把每条字幕转成语音，按字幕时间轴自动对齐，与原声混合/覆盖/仅配音三档可选。

## 环境准备

需要本机已安装 Python 3.9+（tkinter 为 Python 自带，Windows 官方安装包默认包含）。

在本目录打开命令行执行一次:

    pip install -r requirements.txt

依赖:imageio-ffmpeg（绿色 ffmpeg，无需单独安装）、edge-tts（仅字幕配音需要）。

## 启动

双击 **启动视频剪辑工具.bat** 即可（pythonw 后台启动，无黑色命令行窗口）。
若双击后没有窗口，改用命令行执行 `python editor_app.py`，根据报错排查（多为依赖未安装）。

## 使用说明

1. 时间支持三种写法:`40`（秒）、`1:23`、`00:01:23`，也支持 `1:23.5`。
2. 输出文件默认与源视频同目录，文件名带功能后缀与时间戳，**绝不覆盖源文件**。
3. 拼接前用「上移/下移」调整顺序，至少需要 2 个视频。
4. 字幕文本不要过长；单条配音时长超过字幕间隔时可能与下一条重叠（V1 按自然时长对齐）。

## 注意事项

- **字幕配音需要联网**（访问微软 edge-tts 服务）；断网时请取消勾选，仅烧录字幕可完全离线使用。
- SRT 建议使用 UTF-8 编码；导入 GBK 编码的 SRT 会自动尝试识别。
- 中文路径、中文文件名已做兼容；如字幕烧录异常，请把视频放到纯英文短路径后重试。
- 所有处理均在本地完成，除配音请求直发微软 TTS 服务外，不上传任何视频数据。
