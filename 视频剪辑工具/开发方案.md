# 独立视频剪辑工具 · 开发方案文档

> 文档版本:V1.0 ｜ 创建日期:2026-09-13
> 形态:**独立桌面程序（非插件）**，与 AI 智能助手插件体系完全解耦，双击 bat 即可启动，零侵入主程序与录屏插件。

## 一、需求背景与目标

现有录屏插件只能录制与成片变速，无法对视频做后期处理。用户需要一个**可自行操作**的独立小工具，完成:

1. 导入本地视频，裁剪指定片段（快速/精确两种模式）
2. 多个视频按顺序拼接（快速/兼容两种模式）
3. **【V1.0 新增】添加字幕**:支持导入标准 SRT，也支持在程序内按时间轴逐条编辑字幕，最终烧录进画面
4. **【V1.0 新增】字幕转语音配音**:将每条字幕文字通过 TTS 生成语音，按字幕时间轴自动对齐合成配音轨，与视频原声混合后一起播放输出

目标:参赛演示视频可在本工具内一站式完成「裁剪 → 拼接 → 字幕 → 配音 → 导出 MP4」。

## 二、技术选型

| 项 | 方案 | 理由 |
|---|---|---|
| 界面 | Python 自带 tkinter / ttk | 零新增 GUI 依赖；纯文字按钮无图标，保持界面整洁 |
| 剪辑内核 | imageio-ffmpeg==0.5.1 绿色 ffmpeg | 与录屏插件同款已验证依赖，免安装 ffmpeg、不随包分发二进制 |
| 视频探测 | 解析 `ffmpeg -i` 的 stderr | imageio-ffmpeg 不含 ffprobe，复用录屏插件成熟做法 |
| 字幕烧录 | ffmpeg `subtitles` 滤镜（libass） | 支持 SRT、字体大小/颜色/描边/位置样式 |
| 文字转语音 | **edge-tts**（微软 Edge 在线神经网络 TTS） | 中文音色自然（晓晓/云希等）、依赖轻量（仅 aiohttp）；参赛演示效果好 |
| 配音时间轴对齐 | ffmpeg `adelay` + `amix` 滤镜链 | 每条配音按字幕起始毫秒延迟后混合，间隔自动留白 |
| 耗时任务 | 后台线程 + 队列，进度条回调 | 界面全程不卡死 |
| 启动方式 | `pythonw` 后台启动 bat | 双击无黑窗，写法对齐录屏控制台 |

## 四、功能设计

### 4.1 选项卡一:视频裁剪

- 导入视频后自动显示:文件名、时长、分辨率、帧率、有无音轨、文件大小
- 开始/结束时间支持三种写法:`40`（秒）、`1:23`、`00:01:23`，自动校验区间合法性
- 快速裁剪:`-c copy` 流拷贝，秒出，关键帧对齐
- 精确裁剪:重编码（libx264 + yuv420p），帧级精确；有音轨自动转 AAC
- 输出默认与源同目录，文件名带 `_裁剪_时间戳`，**绝不覆盖源文件**

### 4.2 选项卡二:视频拼接

- 逐个导入多个视频，列表展示，支持移除、清空、上移/下移排序
- 快速拼接:concat demuxer 流拷贝（参数一致时秒出）
- 兼容拼接:逐个统一重编码为相同分辨率/帧率/像素格式（以第一个视频为准缩放补黑边），缺音轨自动补静音轨，再无损合并；**分辨率不同也能拼**
- 输出 `视频拼接_时间戳.mp4`，H.264 + faststart，可直接上传 B 站等平台
### 4.3 选项卡三:字幕与配音（V1.0 新增核心）

**字幕来源（二选一或结合）**

1. **导入 SRT**:选择标准 `.srt` 文件，解析为字幕条目列表（序号 / 开始时间 / 结束时间 / 文本）
2. **程序内编辑**:表格形式逐条增删改，每条填写「开始时间、结束时间、字幕文本」；时间支持 `秒`、`分:秒`、`时:分:秒`；可一键导出 SRT 备份

**字幕样式（前端可配，全部走 ffmpeg subtitles 滤镜参数）**

- 字号（默认 22）、字体颜色（默认白色 `&H00FFFFFF`）、描边颜色（默认黑色）、描边粗细（默认 1.2）
- 位置:底部（默认）/ 顶部；底部边距可调
- 烧录前可选择「仅加字幕」或「字幕 + 配音」一起导出

**字幕转语音（TTS）**

- 引擎:edge-tts，默认音色 `zh-CN-XiaoxiaoNeural`（女声晓晓），下拉可选 `zh-CN-YunxiNeural`（男声云希）、`zh-CN-YunjianNeural`（云健）等
- 语速/音调可调（如 `+0%`、`-10%`）
- 逐条字幕生成独立 mp3 到临时目录，界面显示生成进度；单条失败可重试，不影响其他条目
- 网络要求:edge-tts 需联网访问微软 TTS 服务；失败时明确提示「配音需要联网，可改用仅烧录字幕模式」

**时间轴对齐与混音（核心算法）**

1. 每条配音按其字幕起始时间用 `adelay=毫秒|毫秒` 延迟
2. 所有配音轨用 `amix=inputs=N:duration=longest:dropout_transition=0` 混合成一条配音轨
3. 与视频原声混合:可选「配音覆盖原声」「配音+原声混合（原声音量可调，默认 30%）」「仅配音」
4. 若原视频无音轨，用 `anullsrc` 补静音底轨后再混合，保证滤镜链稳定
5. 字幕用 `subtitles` 滤镜烧录进画面，最终统一重编码输出 H.264 + AAC + faststart 的 MP4

**输出**:`字幕配音_时间戳.mp4`，与源文件同目录，不覆盖任何源文件；中间临时音频/字幕文件放系统临时目录，完成后自动清理。

## 五、安全与体验设计

- 所有 ffmpeg 子进程统一加 `CREATE_NO_WINDOW`（0x08000000）标志，杜绝黑窗闪烁（复用录屏插件同款做法）
- 通过 ffmpeg `-progress pipe:1` 管道实时解析 `out_time_ms` 换算百分比，进度条 + 日志区双反馈
- ffmpeg 失败时弹出其 stderr 末尾 300 字错误信息，便于定位
- 路径与时间参数全部前置校验:文件存在性、时间区间、至少 2 个视频才能拼接、字幕文本非空
- 仅处理本地文件；除 edge-tts 配音请求直发微软外，不上传任何数据
- 全部按钮纯文字、无图标

## 六、明确不做（V1 边界）

可视化时间轴拖拽、转场特效、贴纸画中画、多轨混音器、语音识别自动生成字幕（ASR）、离线 TTS 音色包；不改动主程序与录屏插件一行代码。

## 七、关联影响

- **零侵入**:新建独立顶层目录 `视频剪辑工具/`，插件市场、主程序、打包流程均不受影响
- **依赖**:imageio-ffmpeg 录屏插件已安装则天然满足；edge-tts 为新增轻量依赖（aiohttp），README 给出一行安装命令
- 项目手册第四章登记开发计划、第五章登记风险摘要

## 八、开发顺序与测试要点

1. 启动 bat → requirements → 剪辑内核 core → GUI 主程序 → README
2. 每个文件创建后立即读取校验
3. 测试要点（交付用户真机测试）:
   - 双击 bat 能否无黑窗启动、无 ffmpeg 时的报错提示
   - 快速/精确裁剪各一次，校验输出时长与起止点
   - 用两个不同分辨率的录屏 MP4 测兼容拼接
   - 手写 3 条字幕走「仅字幕」导出；再联网走「字幕+配音」导出，核对口播时序与原声混合比例
   - 中文路径、中文 SRT（UTF-8 编码）能否正常烧录
